# Universal Review · 通用终审

**语言 / Language:** [简体中文](README.md) | [English](README.en.md)

一个用于最终交付的通用审查技能。适用于财报和投资材料、董事会与高管办公室、完整稿件、代码和数据项目，以及研究、设计、翻译、活动等其他成品。它按对象和风险细分真实专家，保留可追溯证据，把审查、方案、授权修正与最终复核串成连续流程。

## 能力

| 审查对象 | 核查重点 |
| --- | --- |
| 数字、财报、基金与表格 | 全量盘点数值；可计算项实际用工具复算；按主体、期间和适用准则核合并/单体、确认/截止、现金可动用性、基金条款与分配；金融/财务/预算及其他决定性派生值由异人独立复算，相应直接原值另作异人回源；检查隐藏内容、公式、缓存、实际引擎和最终披露 |
| 文字、公文与传播 | 错别字、称谓、文种、引用、日期、条件、程度和承诺；保护原意，减少空泛修饰；核法律原始依据、事实适用及标题截取误读 |
| 管理、高管办公室与决策 | 战略取舍、现金和资源约束、董事会保留事项与真实批准、原话与发声授权、组织权责、激励公平、投后和跨部门督办；定性判断用证据与反例，不编造评分 |
| 代码、数据与专业技术 | 实际入口、需求到实现、代码/脚本/配置/模板、真实测试和失败路径、安全隐私与信任边界、迁移兼容及回滚、数据/AI方法、发布写集和最终版本一致性 |
| 研究、创作及其他任务 | 按目标、输入、方法、输出、受众和失败后果生成适用检查；不把企业制度或工程架构套到无关对象 |

专家人数由实际覆盖需要产生，没有固定总人数或并发上限。所有适用问题都有具名责任、直接证据和最终非作者复核；重大或跨专业风险另配不同身份的原源反证。低风险可合并初审，但须说明终版复核覆盖。协调者按依赖与平台能力分批运行，增加有不同核验问题的专家。

公司级审查先盘真实实体、地区、业务线、管理职责和生命周期，再映射原始材料、责任人、审查者及跨部门接口。一份文件可由多个专业共同审查；产能、收入、现金、融资、人力和交付等相互影响的结论必须汇合。少数文件通过不代表全公司通过，未知业务和缺失材料会明确列为未覆盖。高管讲话和重大活动另核口径版本、批准状态、实际朗读与现场演练证据；机器计时不等于讲话者彩排。

审查开始时先核当前工作区适用的规则，在该任务专属、获准使用的过程区集中保存草稿、计算、测试、日志和审查证据，并与正式交付及发布文件分离。清理只针对本任务已确认可清理的对象；原失败、必要回滚和审计证据按实际留存要求保护。过程目录由项目规则和用户授权决定，Skill 不依赖任何私人知识库路径。

## 使用

完整终审并自动修正已有授权范围：

```text
使用 $universal-review 对这份交付物进行完整终审，先给审查报告和逻辑闭环修正方案，再按已有授权连续修正，最后独立复审全部改动和最终成品。
```

明确授权改稿：

```text
使用 $universal-review 终审这些材料。我授权在保留原件的前提下修正材料中的问题；请连续完成报告、方案、修正和独立复核，不进行发布或其他业务操作。
```

只要报告和建议：

```text
使用 $universal-review 全面审查这份方案，交审查报告和推荐修正方案，不修改原件。
```

若希望亲自选择方案，可明确说“先交报告和方案，等我决定后实施”。已有授权不会被重复询问；正常内部批次不要求回复“继续”。用户反馈、新问题或来源变化会更新方案和受影响检查。

## 执行与交付

1. 核实目标、当前材料、有效要求、来源、版本、授权和实际工具能力。
2. 盘点全部适用对象与依赖，按风险派真实专家独立取证、计算和交叉核验。
3. 形成可审阅的报告与推荐方案，核方案自身的逻辑、数字、影响、验证和恢复方法。
4. 在实际授权内作最小必要修正，同步受影响的表格、引用、脚本、模板、输出和使用入口。
5. 最后一次修改后，由非作者复核完整修正并集、相关依赖及整件最终成品。

交付包括：最终成品、审查报告、推荐方案、实际修正对应表、计算/验证与独立审查证据、最终版本和未核项。内容质量、决策支持、批准、执行和发布状态分别说明；内部审定稿不冒充已获批准或已发布。

真实故障、限流、缺少原始资料或用户明确暂停时保留检查点，恢复后按同一方法接续。旧失败、旧报告和历史版本保留；当前有效规则与引用保持明确一致。

## 安装与管理

通过 [Skills CLI](https://github.com/vercel-labs/skills) 从 GitHub 全局安装：

```sh
npx skills add yunming-yan/universal-review-skill --skill universal-review --global --agent codex claude-code --yes
```

只用 Codex 时保留 `--agent codex`；其他运行环境使用 CLI 支持的实际目标名称。`--global` 表示当前用户级安装，供各项目使用。

```sh
# 查看全局安装
npx skills list --global

# 从 GitHub 更新此 Skill
npx skills add yunming-yan/universal-review-skill --skill universal-review --global --agent codex claude-code --yes

# 卸载此 Skill
npx skills remove universal-review --global --yes
```

命令接口核对版本为 Skills CLI 1.7.0。明确指定目标可避免该版本自动选择不支持全局安装的平台；更新使用上述指定目标的 `add`，不依赖该版本 `update` 的自动目标选择。

## 环境与边界

Skill本身是可移植的工作方法，需要宿主提供真实子代理、文件访问及相应计算/验证工具。计算辅助脚本使用 Python 标准库；复杂金融模型、工作簿、法律与其他专业任务仍使用适配其真实方法的工具和来源。读取 Excel 缓存不等于重新计算，脚本成功也不等于业务结论正确。

它不赋予业务决策权、专业执照、发布或付款权限，不声称任何企业认证。公开财报和官网资料不能证明已取得小米、顺为、Apple 或任何组织的内部规则、完整数据和全部审查权限；结论只覆盖实际读取与验证的对象。缺少原件、计算环境、独立复核或必要签署时会说明 PARTIAL/UNVERIFIED/BLOCKED；严审降低遗漏风险，不能保证任何模型在任何任务中绝对无错。
