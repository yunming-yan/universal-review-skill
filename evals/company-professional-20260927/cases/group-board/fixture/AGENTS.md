# Synthetic board packet workspace rules

This is a fictional review exercise. Keep the provided `sources/` files read-only. The actor may write corrected deliverables only under `delivery/`. Put all calculations, test outputs, draft alternatives, reviewer reports, logs, source snapshots, and recovery evidence in a unique `work/sessions/<task-id>/` directory. Do not place process files in `delivery/` or include them in a release/export. Use actual absolute paths and inspect generated file lists. Do not delete anyone else's task files.

No real money, company communication, appointments, external search containing these fictional records, or publication is authorized. A report may recommend a decision but cannot record an unmade decision as approved. Current task user instructions take precedence over project conventions.
