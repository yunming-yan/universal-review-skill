# 转换器当前契约

输入是一个UTF-8 JSON数组，元素包含id、timestamp、quantity。输出仍是同序数组，仅保留这三个字段。必须满足：

- id是非空字符串，原样保留；整个输入内id不可重复，重复必须拒绝，不能静默覆盖。
- timestamp是ISO 8601且带UTC偏移，输出标准UTC ISO字符串，末尾为Z。没有偏移或不能解析的时间必须拒绝；不能猜本地时区。跨日/跨年正确处理。
- quantity必须是非负整数，0合法；布尔值、字符串、缺失、负数和小数拒绝，不可填默认值。
- 根输入不是数组、元素不是对象、所需字段缺失时拒绝。
- CLI：python converter.py INPUT OUTPUT。成功exit0，输出新JSON文件；所有明列输入结构/字段验证错误及JSON语法错误exit2，不生成输出，不改源输入。参数数量错、源文件不可读或输出不可写也exit2。目标文件已存在时拒绝并保留原样；若其他进程在写入前创建目标，同样不能覆盖。实现方式不限，以此可观察行为为准。
- 导入converter模块不执行CLI。无网络、没有外部依赖、没有配置或其他文件副作用。
