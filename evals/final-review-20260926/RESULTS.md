# Final-review evaluation observations

These are finite synthetic tests, not certification of a company, a profession or universal correctness. The requested actor and specialist configuration was `gpt-6-sol`, reasoning `max`. Initial test actors used fresh contexts; later finalization pooled work in existing identities across different cases. Each target's independent final reviewer was not its modification author. This context reuse is not a claim of statistically independent blind trials. Configuration requests and locally recorded identities are not independent backend attestations.

## Version and protocol

The complete workflow and routing runs use the exact files in [skill-manifest.json](skill-manifest.json). Five guided micro-tests used the preceding candidate: its instructions were identical, but its optional arithmetic helper and helper documentation still used the prior cleanup-error status. The final helper distinguishes a complete published result with pending temporary-file cleanup as exit `3`. Those five micro-tests must not be described as executions of the final helper bytes.

The coordinator supplied source locations, actual resource availability and status reminders. Acting reviewers could not read scoring guides. Complete cases allowed real independent subagents; micro-tests deliberately prohibited them in both conditions. Sources and finished outputs were hashed, failures retained, and non-actor graders examined original sources and outcomes. These runs are not strictly unassisted model benchmarks or a preregistered causal experiment.

## Arithmetic helper

The published helper passed 26 regression tests on Windows CPython 3.12.13 and 3.14.7. A non-author separately exercised eight publication-state paths on each interpreter. Earlier independent arithmetic probes covered 75 exact values and 68 displayed values; their 18 arithmetic/schema AST nodes were unchanged by the final publication-state repair. This is explicit reuse of unaffected evidence, not a claim those probes were rerun against changed bytes.

Independent review found and corrected partial output publication, ambiguous ratio units, negative-baseline growth semantics, unclear digit limits and misleading failure status after successful publication. Retained failure records distinguish these iterations. The final states are complete publication/cleanup (`0`), no publication by this attempt (`2`), and complete publication with cleanup pending (`3`). Existing or concurrently created targets are preserved. Platforms without the required hard-link support have no overwrite fallback.

The public-layout test copy also ran all 26 tests successfully. Helper tests do not authenticate source references, choose business definitions, establish units or replace independent financial-model review. Mac/Linux filesystems and other Python versions were not exercised in these runs.

## Reading the evidence

Published fixtures, original rubrics, calibration, tests and byte manifests support reproduction. Private execution archives contain detailed tool outputs, local identity observations and independent reviews; those archives are not published and are not vendor-signed. Hashes establish byte correspondence only. Static validation, script tests, scenario behavior, professional judgment and actual deployment are distinct claims.

This suite does not test a live multinational company, an actual investment decision, employment action, legal opinion or public announcement. Missing sources or authority must remain visible even when an internal draft is coherent. New models, environments, task types or materially changed Skill versions require their own appropriately scoped verification.
