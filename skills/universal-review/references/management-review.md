# 管理与决策材料终审

适用于战略、经营、组织、投资、治理和高管办公室等材料。审查目标是判断**材料能否支持它声称要支持的决定**；审查者不代替有权者批准，也不因修改材料而触发业务行动。先核当前成品、用途、受众、时点、主体和有效来源，再按真实风险拆给不同专业主审、异人反证与非作者总审；派遣和终版复核遵循 [专家编排](expert-orchestration.md)。

## 六条状态轴，分别取证

| 轴 | 要问什么 | 可观察的证据与常见错位 |
| --- | --- | --- |
| 事实 | 实际发生什么，主体、期间和口径为何？ | 原始记录及版本、日期、直接责任方；把签约写成交付、把目标写成结果是错误。 |
| 推断 | 原始事实是否支持因果或预测？ | 假设、算式、比较对象、替代解释；相关性和单一事件不证明动机。 |
| 建议 | 选项与推荐是否符合目标、约束和机会成本？ | 至少一个可行替代及放弃理由、资源和影响；“值得做”不等于已批准。 |
| 批准 | 谁能作决定，具体批准了哪一版、哪些条件？ | 章程、权限表、决议、签署或正式确认；口头倾向不是正式批准。 |
| 执行 | 谁实际付款、签约、任免、发布、上线或通知？ | 操作工单、签约件、付款/发送/发布回执；批准也不证明已经执行。 |
| 交付效果 | 对承诺对象产生什么结果，后续是否纠偏？ | 验收、回款、质量/用户记录和复盘；完成动作不等于兑现收益。 |

把六轴逐条映射到同版成品中的关键断言。来源可分事实原件、规则原件、推算原件、授权原件和执行回执；各记主体、法域、期间、版本和权限。二手摘要只指向原件，不能替代原件。无源、来源冲突或权限不明时写明缺口；不得用自信语气代替核验。[证据与状态](evidence.md) 管理整体放行，[可复算数值终审](quantitative-review.md) 管理实际计算及异人复算。

## 定性判断要可反驳

对每个决定性判断，记录：①主张与用途；②支持它的具体事实及反面事实；③至少一个竞争解释或真实替代选项；④成立前提和资源约束；⑤谁受益、谁受损、谁未被听见；⑥谁有建议、批准、执行和复核权；⑦短期效果与长期代价；⑧何种观察会使判断失效、暂停或重开。审查者可明确推荐，但要标出其证据边界。对定性事项不编造分数、概率、权重、人物心理或“行业标准答案”。缺数值输入时列所缺字段及可能改变结论的方向，不填想象的金额。

反证不能只换人重复同一摘要。让异人读另一原件、从反方利益或最差可信情景出发，提出“若推荐错了，最先出现什么信号”；核查该信号能否在计划内被监测。意见不合时保留各自主张及适用条件，沿原件与责任权属裁定，不投票平均。

## 按管理问题查缺口

| 触发 | 审查问题 | 具体可观察证据 |
| --- | --- | --- |
| 战略选择、进入或退出业务 | 客户与竞争事实是什么？为何现在做，放弃什么？现有能力、资本和组织能否承载？ | 原始客户反馈、竞争替代、资源约束、项目组合、阶段门槛与停止条件。 |
| 增长、定价、预算、扩产或降本 | 利润和现金先于规模受到什么影响？回款、库存、资本开支、成本与费用是否同期间？ | 总账与银行流水、应收/应付、预算版本、产能和敏感性；数值由独立路径复算。 |
| 组织设计、人员或激励 | 目标、权责、能力和负荷是否一致？标准是否透明公平，申诉和利益冲突如何处理？ | 岗位/绩效原件、政策、员工意见、授权、薪酬兑现与留任风险；不以人格类型或固定淘汰比例代证。 |
| 高管会议、讲话、对外承诺 | 原话、已决定、待确认和建议是否分开？公开主体、受众及后续兑现责任是谁？ | 原始记录、批准稿、版本差异、事实卡、对外发布回执及承诺跟踪。 |
| 投资、治理或重大合作 | 交易价值与协同是已得还是预测？谁批准、谁回避，投后谁交付，何时退出？ | 条款、尽调、权属、资金、治理决议、整合/投后计划及退出约束。 |

完整企业跨业务触发与独立验证路径见 [企业跨业务触发](enterprise-domains.md)。表外风险继续拆专业问题；无关项可按触发组记录有据的排除理由，边界不清或专案要求者逐项说明。高风险内容需要真实原源、有效规则和事实适用的独立核查；法定、合同、用户要求或实际能力边界需要持牌/机构复核签署时，相关正式意见、决定或发布另记未满足条件。内部材料的内容审查不冒充机构认证，也不无依据增加普遍签署门。

## 修正与交付边界

审查报告按“发现位置 → 原件/反证 → 对谁造成何种后果 → 精确修正 → 责任与复核条件”写。修正表达不能改变原始记录：若公开承诺有误，保留原话并拟真实更正；新加条件必须明示是新补充。不能把真实产品、人员或客户问题写成单纯舆情问题。含保密内容只给必要人员受控访问，同时保留必需的审批、访问和决策记录。

把每项建议闭成动作、责任人、期限、观察信号、重开或退出条件；区分近期止损与长期结构投入及其机会成本。先形成可审阅报告和方案，再按用户已有授权连续修正、验证并让异人复核最终同版；若用户明确要求先看方案才实施，遵守该条件。**修稿授权仅涉及材料**，不推出付款、签约、终止雇佣、召回、申报、发公告或系统操作的批准或执行。内容可审定、建议可供决策、真实批准、实际执行/外发分别报告状态，互不代签。
