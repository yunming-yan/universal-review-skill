# 文字、数字与自然表达

## 先建立事实锁

逐对象保存：主体/来源、专名、日期、数字与单位、状态、引用、条件、否定、范围、概率、承诺强度、因果关系及机器字面量。先核事实，再润色；修改这些内容须有可追溯依据。

事实锁按每条断言记录，不按整份文件共用来源日期：`断言ID｜主体/属性｜值与单位｜状态/限定｜来源定位｜该事实截止日或未提供｜证据强度`。
已知日期仅修饰对应事实；同页其他资料没有日期时，保留缺口。日期缺失不等于数字必错，但不能自行补上邻段日期。
标题、摘要、表格表头和脚注也是断言：合并来源说明中逐项区分日期适用范围，不写一个“截至某日”统领无共同日期的材料。

相同数字不代表相同事实。预算不是报价，报价不是合同，合同不是实付，计划不是已执行，自评预计不是测量结果。一个对象的资料不能补到另一个对象里。

例如，来源为“预算80万元，已批78万元”，可写“预算缺口2万元”；不能写“报价80万元”“合同已确认80万元”或“费用已经支出80万元”。这不是同义改写。

## 逐句文字核对

- 错字、漏字、重复、语法、指代、标题层级、标点和前后称谓。
- 每个事实断言能否落到来源，来源是否支持相同主体、时间、范围和强度。
- “至少/至多”“不/尚未”“可能/预计/已经”“必须/建议”“仅/全部”等词是否被误删或增强。
- 原话、法律/合同措辞、专名、产品名、变量、命令、API、URL和标识符是否需要逐字保留。明确的引文内部不擅自修饰，疑点在引文外说明。
- 段落顺序和论证是否自然，结论能否由已知事实推出；建议与事实分开，未知继续标未知。
- 表格、图例、脚注、附件、摘要与正文是否一致；不只校对主段落。

## 逐项数字核验

为重要数值记录来源/日期、单位/币种/精度、对象范围、分子分母、计算或引用位置及不确定性。适用时用计算工具实际复算并保留输入/结果，不能凭语言流畅判断正确。

| 检查 | 具体问题 |
| --- | --- |
| 合计与差额 | 分项之和、净额、余额、预算缺口和重复计入是否正确 |
| 比例与变化 | 百分比和百分点、同比和环比、增长率和贡献率、分母是否一致；零基数不能硬算普通增长率 |
| 单位与量纲 | 元/万元/亿元、千/百万、人数/人次、时长/时点、面积/体积、税前/税后、币种与汇率日期 |
| 统计口径 | 样本量、总体、时间窗口、排除项、平均/中位数、相关/因果、实测/预测/自评 |
| 表达精度 | 舍入与有效位数、约数与精确数、区间/上下限、当地日期和小数/千位分隔格式 |
| 多处一致 | 正文、表格、图表、公式、摘要、页码/编号、文字描述是否对应同一数值与口径 |

例如20%到22%是增加2个百分点；相对增幅为10%，只有分母、周期和用途明确时才这样表述。不能把预计节省约8%的处理时间改成已验证效率提高8%。

来源缺失时先核当前可用材料；依任务授权可以继续查证，否则明确待核。不得发明来源、把同源转载当交叉验证，或为了填满表格补出缺失数字。

## 自然表达的正向标准

交付正文应让目标读者顺着句子理解“谁做什么、发生什么、凭什么、下一步是什么”。使用熟悉而准确的词、适当句长和有内容的连接，保留必要术语及原作者声音。

删减无信息的铺垫、夸张形容、机械排比、反复总结和不受事实支持的“赋能/革命性/价值重塑”等修饰。判断靠上下文，不靠禁词表；这些词出现在准确引文、作品或有意义语境中时不可机械删除。

自然不等于口语化。报告保持正式而直接；聊天保持自然；学术文本保留技术精度；法律文本保护义务边界；文学和创意文本保留有意的节奏与意象。按任务语言和受众调整，不统一成一种公文腔。

不要添加个人经历、见闻、情绪或作者未表达的立场来“人性化”。不要为了简短删掉实质风险或必要条件，也不要为了“完整”增加未经要求的政策承诺。

## 改稿与审查说明分开

正文只保留读者使用内容所需的信息、来源和真实风险。修改理由、删除了什么、原稿哪处不能这样写、尚未验证的检查过程放入审查说明；若某个缺口直接影响读者判断，正文也要清楚保留该限制。

不把“这组数据不是环比”“我已删除AI套话”等编辑过程塞进普通正文来替代正确表述。保留原有合适风格，不为了显示做过工作而重写每一句。

## 最后保真复审

将改稿逐项对照事实锁：数字/日期/主体/状态/引用/条件/否定/承诺强度是否变化，变化是否有来源。重新计算受改动影响的数字，检查正文与表格/附件是否一致。

再从最终版本反查一次，覆盖标题、摘要、脚注、图例和合并来源说明；日期或来源的修饰范围超出原证据时，拆开表述或去掉无依据的日期，不能仅在文末加免责声明后保留矛盾摘要。

特别回查跨对象串用和近义词漂移：预算→报价、预计→实现、相关→导致、待验收→已完成、建议→承诺。数学正确也可能语义错误。

最后润色后的实际版本才是交付版本。它必须经过非作者复核；任何后续实质改写都要更新受影响检查，不能套用润色前的最终PASS。
