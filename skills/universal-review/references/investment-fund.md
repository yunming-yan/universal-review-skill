# 投资机构、基金与投后材料终审

当对象是基金募集、投资/退出、LP 报告、基金 NAV/分配或 PE/VC 管理人治理时加载；普通企业投资项目可只用实际触发行。先区分管理公司、基金、SPV、共同投资者、被投企业以及各自资金、授权、法域和报告期间，不能把官网投资组合等同基金完整清单。专业合规责任按实际注册/管理/募集地及交易适用的当期一手规则、合伙协议和侧函核，不能全球套一套制度。

## 按资金与权利链审

`出资承诺→调用→到账/托管→投委/投资限制→交易交割→估值/NAV→投后权利→退出款→费用/抵扣→优先收益/追补/Carry→LP 分配和报告`。每一步有主体、账户、日期、合同条款、批准及执行回执。把管理费收入、基金资产、被投企业经营现金和 LP 已分得现金分开。投资收益率必须用有日期的实际现金流、正确定义及工具实算；只用投出/退出总额无法认证 IRR。

| 高风险触发 | 必要原件与独立挑战 |
| --- | --- |
| LP/GP 权利与侧函 | 逐 LP 查优先费用、信息、退出和共同投资权是否与基金协议/其余侧函冲突；从 LP 视角逆查差别待遇、通知与必要同意。 |
| 投资限制、关联交易与回避 | 查投资范围、投委/LPAC 权限、关联买卖或跟投、费用/利益披露、定价独立性；审批缺原件时不得称“已批准”。 |
| 费用、估值、NAV 与分配 | 锁计费基数/期间/抵扣和侧函例外；估值看被投财务与期后事件、方法和估值日；分配按原始流水及完整 waterfall 条款真实重算并由异人另算。 |
| 投后、治理、退出与报告 | 信息权/董事席位/否决权是否可执行，资金与业绩是否来自被投原源；退出条件、税费、外汇和风险准备是否进入 LP 可分现金，回写年报与管理层叙述。 |

对每条关键断言列有利和不利证据、替代解释、触发后果、具名主审/异人、准确版本及终态。先核该基金是否有侧函、投委、LPAC及哪些事项实际触发，不能把某种基金结构套给所有投资机构；确有适用协议、侧函、批准或银行原源缺位时，对依赖它们的法律、费用或分配断言保留未核，不凭缺件直接否定无关内容。修订报告、LP通知候选和计算工作簿后，由未改稿者同版复核；发出调用、签约、付款或LP通知分别需要真实权限和执行回执。
