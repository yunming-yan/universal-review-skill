# 可复算的数字、金融与表格终审

所有数值断言先入清单，不只看“重要金额”：金额、数量、比率、日期/时长、序号/计数、单位换算、排期容量、统计、公式和表格都要分类。凡可计算或可程序核验者，必须真实运行适合的可靠工具并留证，不能以模型心算、看起来合理、口头算式或未执行代码代替。原文直接值核原件，不编不存在的公式。**计算正确、来源可信、业务含义正确是三个不同结论**，不能互相代签。

## 数值门禁 Q0–Q6

| 门禁 | 必须做的实际动作 | 保留的证据 |
| --- | --- | --- |
| Q0 全集 | 枚举标题、摘要、正文、表格、公式、图表、脚注、附件和导出中的数字断言；同一指标各位置关联同一ID。日期、编号、页码和标识仍入原值核对；只排除不适用的算术步骤或经说明确非数值断言的字符，不排除回源和一致性检查 | 完整索引、输入版本、原件定位与非计算项核对结果 |
| Q1 身份 | 每个指标锁主体、属性、期间/截止日、数值、单位/币种、预算/报价/已批/签约/实付/预测/实测状态、原数据定位与证据等级 | 事实锁；缺来源或日期原样标缺口 |
| Q2 定义 | 先核公式、分子分母、纳入/排除、粒度、税/汇率、精度和**预先约定的**舍入与容差 | 有权威的计算定义、原规则或合同指针 |
| Q3 实算 | **派生值、模型和工作簿输出**从受控原始值用真实工具运行并保留实际输入、算法、工具版本与原始结果；命令行工具另留 stdout/stderr/即时退出码，GUI/表格引擎留实际回执、计算状态、错误与结果文件。金额优先十进制字符串转 `Decimal` 或整数最小货币单位 | 可重演的脚本/模型副本或引擎步骤、真实输出、源哈希 |
| Q4 第二路 | 金融/财务/预算的派生值，以及其他重大或决定性派生值，由另一真实身份从原源独立抽取，以不同实现或反向勾稽实算；这些领域的直接原值及其他重大直接原值，由异人独立原件提取并核主体、范围、单位/币种、税口径、条件、版本和状态。其他项目按后果/方法风险升级。比较原始差额，不以重跑第一脚本代替第二路径 | 第二套原源定位、算式/真实输出或原文提取、异人ID、差异处置 |
| Q5 勾稽 | 跨期、跨表、跨媒介核现金、利润、总额与分项、正文与表格/图示/导出；差额逐项定位，不能编“其他调整”填平 | 指标链、差异及解释矩阵 |
| Q6 终版 | 最后修正后重算受影响指标及其依赖，核实际显示、缓存、PDF/图表与最终正文同版，再由非作者复核 | 最终文件版本/哈希、重跑输出和复核记录 |

通用账本槽：`指标ID｜出现位置｜源行/单元格/文件及版本｜对象/期间/状态｜原值和单位｜公式与分母｜税汇率/舍入｜第一实算｜异人第二实算｜差异/证据等级｜终版位置和结论`。原始 source、公式、存储缓存和最终导出分别是不同对象；同一数字不能跨对象偷换身份。

先把数值断言分为**原文直接值、派生计算值、模型/工作簿输出值、日期/标识/计数**。没有算式的合同上限、法条编号或原文日期，执行原件与条件核对，不为显示“已计算”编公式；其一致性、序号唯一性、计数或日期差可以程序检查时实际运行。所有真正派生值都实算，低影响不免工具核验；异人第二路统一按Q4分流，批量数据可用两套独立全量实现，不必每个单元格各开一个代理。工具不可用、原始数据缺失、外链不可达或必要第二路缺位时，分别标“仅原文复核”“算式已核”“来源未核”“工作簿执行未核”，不冒称完整数值PASS。

## 实际计算方法

- CSV/TSV 先核编码、分隔符、引号、空值/零、文本数值、业务键、重复行、筛选和汇总粒度，再算合计；计数相等不能证明集合身份相同。OCR 数字须回看原图区域，尤其小数点、负号、列名与“元/万元”。
- 合计和差额逐项复算；比例先锁分子分母、同期/环比、区间端点与基期。`20% → 22%` 是 **2 个百分点**，相对增幅另算；基数为零或口径变更时不硬算普通增长率。保留原始精度，最终按来源/合同要求舍入，不能为通过事后改容差。
- 原始金额以十进制字符串读入；Python 标准库 `csv`、`decimal`、`fractions` 可形成可重演记录。法定或合同舍入方式先核依据，不将某种舍入、日数或税率定为全球默认。第二路统一按Q4，从原源独立计算或提取，不共用错误公式或缓存。基础显式算术可用 [附带助手](numeric-helper.md)，它不代替取源、口径判断或独立第二路。
- 日期分清时点与期间、财年与自然年、时区、工作日和包含边界。样本与统计核样本量、缺失、加权、波动区间和方法；自评预计不写成实测普遍效果，相关性不写成因果。

## 金融模型与现金流

实际/预算/预测/合同/现金分开。若有财务三表，则核收入→成本→费用→利润、资产=负债+权益、期初与期末变动，以及经营/投资/筹资现金流与资产负债表现金的连接。利润不等于现金；已签合同不等于收入；预收款按实际有效确认规则核实；成本已支付不代表本期已确认费用，存货/资本化与应付也会改变口径。项目贡献额不能冒充公司净利润；现金净流入不能冒充期末现金。只有部分数据时只签对应链，不补齐缺失报表、税率或期初余额。

融资、估值和利率另核时间轴、币种、名义/实际及税前/税后、复利、现金流符号、终值/折现假设、债务/现金调整和关键假设敏感性。税率和汇率需记录适用法域、基准日、官方或任务要求来源、币对及换算方向；不能凭模型记忆把不同货币直接相加。各分项一致但总账不平时指出原始差额及可能分类，不虚构调节项。

金融建议由数值审查与业务/风险审查交叉：算法正确不能代替来源真伪、会计准则、税法、估值可比性或偿付能力判断。需要持牌签署、正式审计或监管确认时保留该实际外部条件，不把 AI 专家身份写成资质。

## 工作簿、公式与缓存

在保留原件的副本上盘点**全部**工作表，包括隐藏和 `veryHidden`；核隐藏行列、筛选、合并、命名区域、透视、图表来源、外部链接/查询、宏/UDF、手动计算模式和错误值。重要指标追到源行、公式文本、相对/绝对引用、跨表链、范围末行与硬编码；按业务键查是否重复、漏入或漏出。

读取 `.xlsx` 的公式文本或 `data_only` 缓存**不等于重算公式**；例如 `openpyxl` 能读结构和缓存，但不能执行 Excel 计算。使用与交付工作簿兼容的实际引擎，在隔离副本上重算；按Q4从原始数据独立核派生值或提取原值，财务全量第二路可用独立批处理。引擎不支持的函数、宏、外链或动态查询分别标未核。未知来源的宏/外链不擅自启用或刷新。

再实际查看最终表格和导出的 PDF/图表：值虽算对，显示负号、单位、舍入、隐藏列、裁切或图表轴错误仍会误导读者。大型表格可用程序全量枚举行、公式和依赖，再对高影响及异常分支人工回读；抽样人工判读不能取代可程序化的全集核查。所有未解释的核心差额或无法重新计算的关键工作簿值阻断数值终审 PASS。
