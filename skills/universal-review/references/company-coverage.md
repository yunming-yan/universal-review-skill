# 公司级全景覆盖与同件联合审查

当任务声称审查**集团、投资机构或企业的全公司业务与管理**时，先用本文件建立真实业务全景，再按 [覆盖本体](coverage.md) 与 [专家编排](expert-orchestration.md) 审具体对象和风险。[企业跨业务触发](enterprise-domains.md) 提供深入问题，不能代替全景发现。单篇材料即使不属公司级任务，也可按下文“同件联合审查”派多个专业。这里的职责词库不证明任何企业具有全部部门或流程，也不设专家人数下限。

## 先发现实际业务，再圈审查范围

1. **锁定全称范围。** 写明受审法人、子公司、基金/特殊目的实体、合营或受托业务、外包职能、地域、产品/服务、渠道、所处生命周期及报告期间；分清“总部文件”“集团合并口径”“某子公司”与“全公司”。审查授权和可读系统逐实体记载。尚未确认的实体、地区和期间标未知，不能按未出现处理。
2. **四路资料盘点。** 对照①法人与股权/基金架构、章程和牌照；②组织图、岗位职责与授权矩阵；③总账/预算/分部信息、银行/资产及交易台账；④客户/供应商合同、业务系统、流程图、风险/事件台账。这是四种来源视角，不是固定四名代理。使用已有访谈记录发现遗漏和解释冲突；联系责任人仅在当次已获联系授权时进行，并回查原件。组织图没有某职能，不证明真实交易和外包义务不存在。
3. **按实体×地域×业务线×生命周期展开职责。** 生命周期至少问筹划/研发或投资、采购/建设、交付/运营、售后或投后、退出/处置；并查管理支持与突发事件。对每项职责登记 `存在且适用 / 有证据证明不适用 / 尚未知`。外包、合营和委托业务仍要审本公司保留的选择、监督与责任接口。
4. **用交易链反查遗漏。** 从战略→预算→资金→采购/投资→生产/交付→客户验收→收入/回款，产品→质量/安全→售后，基金募集→投资→投后→退出，以及决策→授权→执行→记录→内控审计各走至少一条真实链；按本公司业务增删链。链上缺 owner、证据、数据口径或交接回执即开发现，不用“部门已审”抵销。
5. **确定审查单元与并行度。** 每行至少记 `实体/地域/期间｜职责及触发｜原件/系统及版本｜业务owner｜主审与终版非作者｜重大/跨专业的另行异人原源反证（低风险合并给依据）｜接口owner｜问题/修正｜最终状态`。下表owner是**待核岗位占位**，不得当成已具名；用实际方法能力与独立性选真实身份。各行数字的第二路统一按Q4；人数由真实任务产生。

## 职责到证据、责任和最终状态

表内“主/异”列两种审查视角，重大/跨专业风险才据此另派不同身份原源反证；低风险可合并初审，但保留具名责任、证据和终版非作者覆盖。Q4另有强制数值分流，不因低风险合并而豁免。“终态锚”是该职责的证据/决定状态；每行另记 `PASS / PARTIAL / UNVERIFIED / BLOCKED / NOT-APPLICABLE` 与同版对象，业务批准、执行、发布分列。表外职责加行补证据和专家，本表不穷尽企业职能。

## 同一文件的多专家联合审查

合成例：`扩产兼产业投资报告 v7` 的首页写新增产能和收益结论，正文有现金流表、估值附件、供应商合同前提、投产日期、招聘计划及对客户的交付承诺。**这只是测试材料结构，不是实际企业事实。**按下表将同一文件拆成可核断言，专业审查可以并行，涉同一数据和条件的核对必须汇合。

| 同件位置与断言 | 主审、异人和原源 | 必须汇合的接口 |
| --- | --- | --- |
| 首页“产能提升、投资可行” | 战略主审查替代用途；运营异人查设备/瓶颈原件 | 产能定义、投产日期与现金表同版 |
| 现金流/利润/IRR表及图 | 财务主审从账簿和公式实算；另一人从流水与独立模型复算 | 总投资、税币、期间、折现/情景唯一指标字典 |
| 交易、土地、供应合同条件 | 法务/投资主审查生效条件和权限；异人逆查未满足条件 | 合同条件进入现金、投产和风险章节 |
| 采购、建设、质量、EHS里程碑 | 工程/质量主审查验证；现场安全异人检最坏工况 | 可用产能以验收/许可状态为准，不以计划日期代实绩 |
| 编制、招聘、客户交付承诺 | HR与销售分别主审能力和措辞；交付/客服异人反证 | 人员到岗、交付日期、客服产能回写计划与首页 |

建立 `断言ID｜位置｜统一定义/单位/期间｜原件版本｜主审/异人｜相依断言｜冲突裁定｜最终稿版本` 接口表。同名同口径指标指定权威定义和系统源，不同口径分别命名；不同专家结果不一致时保留各自证据并回源，不能投票平均或局部自行改数字。一个指定 writer 按已审方案整合文字、表、图、合同条件与附件；改后相关专业重新核，非作者再读整件最终版及所有实际改动。无需让每个专家逐字审全稿，但每一重要断言及交界须有责任人。

## 全公司结论门槛

公司级 `PASS` 只对已明确界定的公司范围成立：上述全景的实体、地域、业务线、生命周期和适用职责均有具名 owner、可核原源、必要主审/异人、跨部门接口、问题闭环与**同一最终版本**；有证据的不适用可排除，未知不能。只有少数文件时，先把这些文件按其准确范围审完；在授权的只读范围内自主查组织、账务、系统与流程证据，补出缺席职责。仍拿不到关键资料或真实独立审查时，列明未覆盖实体/流程/系统/期间及所需负责人，整体报 `PARTIAL/UNVERIFIED`，不得把文件级 `PASS` 写成“全公司通过”或宣称穷尽未披露业务。内容、决策支持、内部批准及实际操作/对外发布仍按各自回执分轴；审查和修稿不增加真实业务操作权限。
