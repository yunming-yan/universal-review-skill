# 企业跨业务触发与独立验证

本表供 [管理与决策材料终审](management-review.md) 分诊大型企业、集团和投资机构的实际风险。**按真实业务、材料和用途启用对应行**；公司级先沿公司全景发现业务，不限于初次交付材料。无关项可按触发组说明排除理由，未知不能排除。原件须真实取得且获准读取。每个高风险问题由领域主审直读原件，异人换来源、方法或利益视角反证；内容缺源、动作缺权及依法/依约需要的专业签署分报，不假称认证，也不一概阻断内部候选内容审查。

核验时区分事实、规则、公式/模型、授权和实际执行回执。法律、会计、税、产品认证按**主体、法域、生效时点和版本**查现行一手规则；工具复算不能替代审计、法务、工程、安全或正式决策。数值转 [可复算数值终审](quantitative-review.md)，合同/监管/外发转 [公文·法律·公关](official-legal-pr.md)，证据状态转 [证据与状态](evidence.md)。

| 真实触发 | 具体高风险问题 | 必需原件 | 异人反证与验证 |
| --- | --- | --- | --- |
| 董事会、股东会或保留事项 | “已批准”的每句话是否对应正确主体、议题、出席、回避和表决？对外版本是否越过决议？ | 章程、授权矩阵、通知、原始会议记录、表决和签署决议。 | 从保留事项清单逆查遗漏及反对/回避票；逐句比对决议与稿件。缺表决原件不得称通过。 |
| 董事会包连接财报、交易与高管讲话 | 摘要、表格、模型、合同和讲话稿是否将同一预测、风险、决定或公开状态说成不同事实？ | 议程包及全部附件的同版清单、原始决议、批准稿和实际发布回执。 | 董办/法务主审决议和回避，财务/传播异人各从原源反查共同断言；按 [高管办公室](executive-office.md) 核状态。 |
| 母子公司调资、共用人力、内部交易 | 子公司可支配资金是否被集团合并现金高估？往来、税、定价和抵销由谁负责？ | 单体与合并报表、合并底稿、银行流水、内部协议和各实体审批。 | 从付款实体及单体现金重建资源，核关联余额与抵销；不能用合并口径替代法人边界。 |
| 经营月报、预算或扩产 | 收入到利润再到现金的桥是否闭合？库存、应收、资本开支和一次性收益是否改变结论？ | 总账、管理报表、银行流水、预算版本、应收应付及投资计划。 | 从现金和余额变动另建桥，核截止与账龄；数值全量分类，按Q4作异人派生复算或直接原值提取。 |
| 法定年中报、集团合并或董事会财务包 | 除总账平衡外，合并边界及例外、确认和截止、估计减值、脚注和期后事项是否支持同版叙述？管理口径是否冒充法定口径？ | 报表及附注、单体/合并底稿、凭证合同、调整与适用准则原文。 | 财报主审按断言回源并真实复算；异人从现金、期后交易和不利估计反查，按 [财报方法](financial-reporting.md) 留未核边界。 |
| 订单、补贴、返点或营收宣称 | 预订、合同、发货、验收、收入和收款是否混用？退款或折让是否遗漏？ | 客户合同、订单、交付与验收、发票、贷项及账务记录。 | 逆向抽客户验收与期后冲回，重走订单到现金链；会计规则由适用法域专业方核。 |
| 借款、担保、资金池或现金压力 | 到期、担保、限制条款及交叉违约会否令最差月份失去偿付能力？ | 贷款/担保协议、契约测试、受限资金、期限表与现金预测。 | 独立复算契约指标，找未入表承诺与更紧的现金情景。 |
| 基金募集、LP/GP、侧函、跟投 | 谁承担何种受托/忠实义务？侧函、关联跟投、费用、资本调用和分配是否冲突？ | 基金协议、侧函、投委会规则、调用通知、费用及分配台账。 | 从 LP 与 GP 两侧分别核权利差异与冲突；独立重算分配瀑布和最不利情景。 |
| 基金估值、管理费/Carry或关联退出 | 管理人、基金、SPV和被投企业的现金与权限是否混用？侧函差异、估值日期、费用抵扣和分配瀑布是否影响LP应得及披露？ | 实体资金地图、基金协议及相关侧函、投委/LPAC原件、估值、银行和分配模型。 | 财务异人从条款与流水独立实算；合规异人核真实法域、利益披露/回避和批准；按 [基金方法](investment-fund.md) 区分每个法律实体。 |
| 产业投资、收购或股权交换 | 预测协同是否被计入已实现价值？估值、稀释、优先权、对赌、税费和现金占用是否完整？ | 尽调底稿、历史财报、股权表、条款清单、模型公式及假设。 | 异人用不同估值路径与悲观经营假设挑战交易价格；缺审计/税务源不认证结论。 |
| 投后管理、并购整合、退出 | 治理权、信息权和整合成本能否落地？谁在何时交付协同，失败后如何退出？ | 股东协议、董事席位/否决条款、投后报告、整合计划及退出条款。 | 从被投方实际资金和执行团队检查里程碑，找不可执行的治理权与退出路径。 |
| 关联采购、供应商或任命 | 实益关系和个人利益是否披露？竞价、定价、回避与批准是否独立？ | 关联清单、利益申报、招采报价、评标及审批记录。 | 反查未披露控制关系、替代报价和表决轨迹；关系优势不能替代程序。 |
| 主供方集中、停供或质量索赔 | 单点失效、备选供应、来料追溯和停线损失是否已反映在交付承诺？ | 采购合同、供方审核、库存、批次、来料不良、停线及索赔记录。 | 抽批次逆向追踪，模拟主供方停供；验证备选产能而非只读供方声明。 |
| 工厂设备、职业健康或环境安全 | 危险工况、隔离、停机、报告和复产权限是否明确且现场有效？ | 风险评估、许可与操作规程、维护/培训、现场和事故原始记录。 | 独立安全人员看现场及最严重可信事故，核演练与复产门槛；文稿通过不等于准许复产。 |
| 产品研发、量产、召回或性能宣称 | 宣称使用条件是否被测试覆盖？批次缺陷、售后与召回能力能否兑现安全承诺？ | 需求、设计、测试、质量、批次、投诉、维修及认证/备案原件。 | 技术异人重测失败工况、按真实用户场景抽核；质量异人逆查缺陷范围和服务回执。 |
| 代码、专利、许可、受控技术 | IP 权属链、第三方许可、开源义务和技术转移限制是否影响发布或交易？ | 代码与依赖清单、许可证、研发/雇佣协议、专利权属及目的地规则。 | 从依赖和贡献者逆查权利缺口；独立构建/扫描并核当前规则，工具结果不等于法律许可。 |
| 跨境销售、投资、采购或派遣 | 交易主体、目的地、税/关税、外汇、制裁、出口限制和币种时点是否匹配？ | 合同、发票/报关、付款与汇率记录、税务文件、适用法源原文。 | 当地专业方核法域与要件；异人按最不利汇率/税负复算，写明未核地区。 |
| 招聘、绩效、激励、调岗或裁员 | 标准是否事先可知、一致适用且可申诉？个人证据与业务负荷是否支持动作？ | 岗位标准、绩效原始材料、政策、合同、员工意见与适用规则。 | HR 之外的异人匿名化比对相反个案和受影响群体；不以人格标签或强制分布代证。 |
| toB 合同、投标、toG 项目或 SLA | 销售承诺、验收、回款、罚则、政府采购/反贿赂要求和交付资源是否同版？ | 招标与合同、报价审批、交付计划、验收、客户投诉和合规记录。 | 交付与财务异人从资源及失败项目反推承诺，核条款到现金与责任链。 |
| 客户投诉、危机声明、产品伤害 | 是事实争议、用户感受还是安全问题？是否先补救受影响者，再形成获准口径？ | 客诉、伤害/缺陷、批次、调查时间线、法务与质量意见、批准稿。 | 从受害者及一线客服视角读声明；逆查扩大范围的反例和实际补救回执，不用转移话题代替纠错。 |
| 财务、并购、人事等敏感资料入外部工具 | 信息是否准许出域？最小访问、供应商留存、训练/再共享、撤回和审计怎样落实？ | 数据分级、系统合同/设置、数据流、授权、访问日志。 | 安全异人追踪泄露路径并实际核配置/权限；“个人经手”不能替代受控记录。 |
| 网络入侵、隐私泄露或勒索事件 | 影响范围、证据保全、隔离、恢复、通知和对外声明是否基于同一时间线？ | 系统日志、资产、工单、指挥记录、恢复测试及适用规则。 | 独立技术路径复核入侵与遗漏资产；法务/传播分别核通知期限和事实句。 |
| 付款、签约、关停、发布或申报 | 材料中的“拟议/已批准/已执行”是否对应真实权限和回执？是否有可回滚或应急措施？ | 授权表、实际审批、工单、签署/付款/发布回执及恢复计划。 | 异人从系统与对方确认反查动作是否真的发生、是否越权；修稿权不触发业务动作。 |

不同原件不一定可共享；派专家前先核保密等级、用途和必要知情。审查包仅携必要定位与受控访问，不为证明“独立”把整套敏感材料发给无权人员。每个触发项记录主审、异人、验证原始回执、结论适用版本和未核项；问题修正后回查所有受影响领域，最后由非作者看整件同版成品。若材料只是代码、科研、设计或个人事务，转对应 [任务适配器](task-checks.md)，不硬套本表。
