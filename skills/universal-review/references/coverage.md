# 完整独立终审：33职责覆盖

适用于用户要求的整体项目、工程或完整独立终审。总协调者另计；A00为独立总审，A01–A24为专项，A25–A32为交叉。每个角色使用真实、可核的独立身份，不由协调者自扮多角色。修正作者不得兼任其独审。

33是完整协议的职责起点，不是并发数或人数上限。协调者依据任务依赖、平台能力和资源自主编排；需要时细分增派，保留全部身份与实际运行记录。不能为赶进度、额度或已多轮通过而缩水。平台不支持真实独立能力时，保留缺口，不假签完整终审。

明确的局部请求或被分配的专项，只负责其范围及证据并标LIMITED-SCOPE，不在专项内再次递归启动整个团队。无关技术维度按可核理由说明不适用，不编造不存在的代码、模块或测试。
