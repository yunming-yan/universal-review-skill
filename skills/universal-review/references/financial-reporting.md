# 财报与董事会财务包终审

用于法定年/中期报、集团或子公司财务包、融资披露、重大交易模型和以财务预测支持决策的材料。先执行通用覆盖、证据与 [Q0–Q6 数值协议](quantitative-review.md)；本文件补充财务断言与业务解释，不替代现行准则、正式审计或实际批准。只有所审对象的财务部分触发时才加载。

## 先定报告身份

写明每套数的报告主体/法人/合并边界、准则、财年/起止日期、币种、原值/调整/预算/预测、已审/未审/管理口径、对外状态。法定报表与管理报表、单体与合并、已实现与预测分别命名，不以报表标题推定审计、批准或申报。先取完整报告、脚注、比较期、审计调整、附表、管理层调节、估值和披露底稿；按当前主体和期间查适用的一手会计与监管规则。规则不可得时把相应解释标未核，不用熟悉的其他法域代替。确认合并边界时还要核适用准则的范围和例外；例如[IFRS 10](https://www.ifrs.org/issued-standards/list-of-standards/ifrs-10-consolidated-financial-statements/)对符合条件的投资实体规定某些子公司的合并例外，不能把一般控制原则直接套给每一基金或实体。

## 财务断言到原源

对关键科目、脚注和管理层叙述逐项建 `断言ID｜主体/期间/口径｜存在或发生｜完整性｜准确性与截止｜估值｜权利义务｜列报披露｜原源｜执行程序/结果｜异人复核` 卡；并非每项断言对每个科目都同等相关，排除须有理由。

| 真实触发 | 除算术外要问的关键问题 | 原源与反向检查 |
| --- | --- | --- |
| 合并、分部、母子公司交易 | 控制/权属、投资实体等适用例外与合并范围是否匹配，少数股东、内部往来与抵销是否完整？ | 实体登记、投资/表决协议、单体总账、合并调整底稿和适用准则原文；从银行和往来逆查未纳入实体。 |
| 收入、订单、订阅或渠道返利 | 签约、发货、客户接受、履约、收入、发票、退款与收款是否被混称？ | 合同条款、履约/验收、贷项、账龄、期后退款；从期后冲回及客户侧反查期间截止。 |
| 存货、固定资产、软件/IP或商誉 | 所有权、在途、资本化和减值假设是否与真实使用、产能和市场需求相符？ | 实物/批次记录、合同、测试与运营数据、独立估值、预算及失败情景；不能只核模型算式。 |
| 应收、金融资产、投资估值 | 账龄、回款、信用损失、公允价值模型和被投方资料是否新鲜且可验证？ | 银行/客户确认、期后回款、估值政策、被投财报、可比交易；对无市场报价资产留更强假设反证。 |
| 借款、租赁、担保、或有事项 | 未入表义务、交叉违约、受限资金、诉讼及期后事项是否漏出正文或脚注？ | 贷款/担保/租赁合同、律师函、银行函证、董事会和法务记录；从付款、保单与诉讼台账反查。 |
| 税与跨境交易 | 税基、永久/暂时差异、转让定价和币种是否对应主体、法域与期间？ | 申报、税务账、集团交易协议、汇率来源与本地法规；必要的专业税务意见另列真实状态。 |
| 非 GAAP/非 IFRS 指标、预测与业绩叙述 | 是否完整调节到准则数，排除项、单位和趋势是否一贯？预测假设、敏感性和反例是否可复核？ | 归档版报表、全部调节项、销售/产能/价格及成本原始计划；不能把选择性指标冒充法定利润。 |

## 决策用现金桥

同时展示利润、经营现金流、期末账面现金、受限现金、各法人实际可动用现金、未来到期和支出。合并现金不是集团总部可直接付款的证明；子公司上划需查当地法规、章程、少数股东/贷款条款、税和真实批准。负债/资本开支采用时间轴，至少查最紧月份和会改变结论的可信下行情景；未确认资金流入不能填补已知缺口。若无原始银行和合同，只可报告报表呈列值，不能认证可付款能力。

## 实际执行、交界和终态

数值先全量分类并真实重算；金融派生值及重大原值按 Q4 让不同真实身份独立回源计算或提取，另一人仅重跑首脚本不算第二路。工作簿查隐藏表、公式、外链、缓存及真实计算引擎，实际显示/导出复核。再由懂相应准则的审查者核事实适用及披露，由业务/法务/资金异人查关键假设和可执行性；冲突回源，不以财务模型和董事会摘要投票平均。修正后重算相关依赖并查同版包、稿、表、图、脚注、公告候选，终版非作者再审。

内容审定、会计审计意见、董事会批准、监管申报和对外发布分别报状态。必要原源、可复算项目的实际引擎或Q4异人身份缺位时，给已核范围与精确未核项，不能对所依赖的财务结论签完整PASS。若所缺仅为依法/依约必要的正式签署或批准，可对确已核完的**内部候选内容范围**作单独判断，正式审计、申报或披露仍标未满足；不因无签署抹去已有内容证据，也不把内部候选冒充法定成品。此参考文件不默认IFRS、US GAAP或中国准则；按具体主体、期间和法域读取当期官方原文。
