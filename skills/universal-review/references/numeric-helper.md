# 可选精确算术助手

[numeric_recheck.py](../scripts/numeric_recheck.py) 用Python标准库从**显式十进制字符串**计算精确分数，保留输入、单位、来源定位及账本SHA256。它只辅助基础算术；原始来源、口径、量纲、税币、模型适用性仍由专家核，第二路径仍按 [Q4](quantitative-review.md) 独立完成。不能把助手输出当审计认证。

## 使用

替换为本机Skill和任务工作区的实际路径，不向安装目录或原始材料写结果：

```text
python "<skill-dir>/scripts/numeric_recheck.py" "<task-dir>/ledger.json" "<task-dir>/result-001.json"
```

每次结果用新路径，保留命令、Python/脚本/输入版本、stdout/stderr、退出码和结果文件。exit0表示完整发布且临时清理完成；exit2表示本次未发布（目标原来可能已存在，不能删除）；exit3明确 `RESULT_PUBLISHED_CLEANUP_PENDING`：完整结果已经发布，临时清理未完成，stderr列结果及暂存路径。不能把exit3当未执行而盲重试、覆盖或删除已提交结果。先核完整JSON与对应输入，保留状态证据，在授权范围内核实并处理该暂存文件，再完成相关收尾。stdout为空不代表业务通过，文件存在也不等于成功。

工具先写并核验同目录私有临时文件，再以硬链接原子独占发布。文件系统不支持时诚实失败，没有覆盖/rename退路；不承诺掉电后的目录持久性。结果路径已存在时拒绝，原件不改。可换到当次授权且支持的工作区，不能为通过擅改系统保护。

## 输入合同

根对象只有 `schema_version: 1` 和非空 `calculations` 数组。每项包含唯一非空 `metric_id`、`operation`、字符串数组 `operands`、非空 `unit` 和 `source_refs` 字符串数组；可加 `rounding`。未知字段、重复JSON键/指标ID、缺数、非有限值、科学计数法、千位分隔符和隐式浮点输入拒绝。

| 操作 | 操作数及结果 |
| --- | --- |
| sum | 一个或更多数求和 |
| difference | 恰好两个数，第一减第二 |
| product | 两个或更多数相乘 |
| ratio | 恰好两个数，第一除第二；单位只能为1、times或倍；分母非零 |
| percentage | 恰好两个数，第一除第二再乘100；单位必须% |
| percent_change | 恰好两个数，旧值、新值；(新−旧)/旧×100；旧值必须严格为正，单位% |

`exact_fraction` 永远为最简分数，不默认补小数。请求展示值时必须同时指定 `rounding.places`（0～50整数）和 `rounding.mode`（half_even、half_up、toward_zero），才产生 `rounded_decimal`。舍入是明确展示规则，不是财务政策；精确值不能被展示值替换。负基数增长率拒绝，不自行改成绝对值；跨零结果的业务含义另审。

每个操作数最多1200个十进制数字字符，每项计算的操作数合计最多4000个，符号/小数点不计，前导零计入。保留Python整数保护，不为超限输入静默降精度。本工具在Windows CPython 3.12.13和3.14.7实测；其他平台/版本及文件系统应先验证其实际能力。

`source_refs` 是使用者提供的定位，允许明确空数组以表达没有来源；工具不会打开或认证这些来源，也不会证明单位真实或输入同量纲。空来源可以算数学，不能因此通过业务终审。`input_sha256` 只绑定输入账本，不替代原始资料的版本证据。

## 一个可运行示例

[合成输入](../assets/numeric-ledger-example.json) 仅演示数据格式，复制到任务工作区后使用新结果名运行。例子中的来源定位为虚构，不能作为业务证据。真实任务必须从受控原数据提取操作数并核单位/期间。

独立第二路径要由另一真实身份重新取得原源，另用Decimal、整数最小单位、兼容表格引擎或其他适用实现复算；复跑这个工具或共用作者账本只是复现。日期/时区、IRR、税法、统计和复杂工作簿使用适合的工具，不把所有专业计算塞进基础助手。
