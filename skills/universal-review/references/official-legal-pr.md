# 公文、法律依据与公关终审

正式文书、含法律主张的材料、拟对外发布或可合理预期被转发的稿件，以及虽内部使用但有明显泄露/声誉后果的内容，按实际触发的风险分别派真实专家核**文字与文种、法律依据与事实适用、公关解读与发声权限**；不存在的维度给不适用理由，不机械开齐所有家族。一篇稿子可以在内容上审到该稿最终版；实际签发或公开发布另按授权和真实回执判断。把两种状态写清，不能用润色后的稿件替代批准。

## 公文与正式文字

先识别实际主体、受文对象、用途、渠道、所在法域/组织规则和文种：政府公文、企业正式文件、内部请示/报告、讲话稿、公告或普通文章适用的格式不同。只有在查到当次**有效**规则时，才逐项核标题、主送、编号、层级、附件、日期、发文机关、签发/用印/保密状态；模板外观不能证明组织已经签批或稿件具有法定公文身份。

逐字专家覆盖标题、摘要、正文、表头、图注、脚注、附件及必要页眉页脚，查错别字、漏字、重复、标点、数字写法、称谓、专名、文号、时态和指代。另一名语义专家专核“拟/已经”“原则上/必然”“不超过/至少”“建议/承诺”“经批准后/现已批准”等程度、条件和义务强度，防止公文腔把未知写成确定事实。原话、法律条文、合同用语、机器标识符逐字比对来源；机器校对结果需人工排除误报。保留符合该机构和受众的自然表达，不统一改成空泛官样文字。

对高影响文字，公文格式、逐字校对和发文权限至少是不同的检查问题；后续非作者从最终稿再审标题、数字、引文、附件和未改但受新措辞影响的句子。没有编号或签章依据就保留待办，不编造机关名、批准日、签名、章或“已同意”。

## 法律依据与适用

每条法律主张先建卡：`断言ID｜谁做了什么｜地点/法域｜行为与审稿时点｜已确认事实/缺口｜法律问题｜用途`。跨法域、变法节点或不同事项分别拆卡，不先挑熟悉的条文再倒推事实。

1. **独立法源专家**核该法域当期有权机关或其他任务指定的权威一手文本，记录名称、具体条款、原文限定、颁布/修订/生效/废止与过渡状态、官方出处和访问日期。转载、旧报告、模型记忆与草稿引文只能给检索线索；无法接触权威原文就保留未核，不能虚构条号或声称现行有效。
2. **事实—要件专家**逐项列主体、行为、对象、地域、时间、程序、例外和证据条件，映射到已确认、相反或缺失的事实。区分“适用”“可能适用”“尚不能判断”和“不适用”；结论与法律后果不能强于事实和法源。政策愿景、内部规定、监管指导与具有强制力的法律义务分别标明，不一概称“依法”。
3. **异人反证专家**直接读法律原文与案件事实，检查相反解释、例外、授权、合同特别约定或时效变化；对每条最终法律句从稿件反追实际源。不同专家意见不靠平均化处理，回到有效法源和原始事实解决；实在不明则在最终候选稿与报告中保留界限。

正式法律意见、执业资格、监管背书或机构法律签署不是提示词生成的能力。对重大的外部法律断言，法源不可得、关键事实未核、适用争议未解或需持牌复核时，不能签该法律结论 PASS；可以交可用的安全表述及具体待核事项。审稿 Agent 不代替有权人员批准或签发。

## 公关、声誉与传播

独立记录预计或实际的受众、渠道、时间和传播状态：内部传阅、定向发送、媒体引用和公开发布风险不同。用途未知时明确假设，不能把猜测的发布计划当成已授权任务。

- **事实与标题**：对标题、首段、引语、图表和单独截图仍可见的片段复查限定。不能让“拟/预计/自评/个案/待审批”在摘要中变成“已决定/已验证/全部/零风险”。正文末尾的免责声明不能抵消标题的无据承诺。
- **受众和反面解读**：由不同专家提出合理外部读者会如何理解某句、哪几个字导致误读、影响谁以及如何据事实修正；纯粹个人审美不判作事实错误。媒体、客户、员工、监管者、投资者等身份按实际对象分别考虑。
- **保密、声誉与危机**：查未获授权的个人/商业敏感信息、可识别主体的无证据指控、冒名机构立场、越权承诺和与现行口径冲突。争议/危机场景另核已知/未知时间线、可公开事实、回应窗口、发言人、升级条件及纠错方式。不凭一篇通顺稿宣称“零舆情风险”。
- **跨领域交叉**：数字/金融披露回交数值专家确认单位和状态；法律词句回交法源/要件专家；宣传表述若改变事实强度，重新核原证据与当次发声权限。

公关专家可以给更稳妥的候选表达，但不能代人对外发送。内容终审的 `PASS` 应绑定稿件范围与最终版本；签发、部署、发布等实际状态另有真实批准和执行记录。条件未到时给“内部审定候选稿 + 发布待办/阻断”，不把待发稿说成已经发布。

## 专家输出与最后复核

上述各专家的输出均包含自己的真实身份/输入版本、准确稿件位置、原源/法源或制度指针、该处断言及影响、判断依据、建议修正和未核项。不同专业意见冲突时由协调者根据当前有效要求和原始证据裁决；未经授权的新政策选择留给实际决策者。

最后一次润色后，异人完整复读最终稿。任何数字、法律强度、发文状态或公共传播含义的改变会使相关旧签认失效，并触发对应专家和整稿总审重核。报告把“内容已经审定”“发布条件尚待满足”“实际已发布”分别记录，不用一个含糊 PASS 覆盖三种状态。
